# skills

Self-contained Codex skills live in `skills/<skill-name>/`.

This repo is a source repo for skills, not an auto-discovery location for Codex. To use a skill locally, install or copy the individual skill directory into `$CODEX_HOME/skills` or `~/.codex/skills` or equivalent for your agent.

Current skills:
- `gh-address-comments`
- `gh-fix-ci`
